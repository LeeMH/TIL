# 1. Continuation

- `중단지점`별로 `label`을 생성
- `label`에 따라 실행되는 부분이 상이함


# 2. 자식 코루틴

* 부모에서 자식 코루틴을 호출할때, `continuation`을 전달한다.
* 자식은 `resumeWith` 함수를 호출하며, 결과값을 `data: Any`로 리턴
* 부모는 label 값에 따라, 해당 값을 적절한 변수값으로 변환

# 3. 핵심

* `continuation`을 리모컨처럼 활용
* 부모와 자식간의 값은 리턴이 아닌, `continuation`의 속성으로 통신
* `resumeWith` 함수 호출을 통해 label 변경과 재귀 호출을 통해 연속적으로 동작한다.
* cps = Continuation Passing Style
